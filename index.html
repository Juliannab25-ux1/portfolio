BI-разработчик / Аналитик данных

О себе

BI-разработчик с практическим опытом построения аналитических систем полного цикла: от подключения к источникам данных (API, DWH, Google Sheets) до моделирования, расчётов на DAX и визуализации в Power BI.

Специализируюсь на аналитике продаж на маркетплейсах (Wildberries) — юнит-экономика, рентабельность, комиссии, логистика, ABC-анализ.

Проект 1: Аналитика продаж на Wildberries

Power BI Postgres DAX Power Query Wildberries API

Собрал отчёт для собственника: реальная прибыль с учётом комиссий, логистики и себестоимости; топы лидеров роста и падения; таблица менеджеров с отрицательной прибылью.

Результат: готовый отчёт для принятия решений по ассортименту и логистике.

Проект 2: Аналитика продаж недвижимости

Power BI Report Server DAX UX/UI Документация 280+ мер

Разработал страницу аналитики отказов по воронке продаж, дополнил блок метрик с переключением м²/руб., создал документацию по 280+ DAX-мерам.

Результат: устранил зависимость от ушедшего сотрудника, ускорил адаптацию новых разработчиков.
